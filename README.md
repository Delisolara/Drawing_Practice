# Prakti Draw
Prakti Draw is a simple web app for practicing drawing from reference images. Unlike similar platforms, it allows users to choose their own collections of images, giving them the freedom to practice drawing whatever subjects they want instead of being limited to predefined ones.

This project was created for personal use and as a way to practice coding.

## ⚙️ Technologies

- Vite
- React
- Node.js
- Tailwind CSS
